# CLAUDE.md — Проект OdysseyTour

> Туристический портал (бывш. Endless Line). Курсовой проект, автор — Баринов Николай, гр. ПО2410.
> Стек: HTML/CSS/Vanilla JS + React SPA (`react-tours.html`), backend Node.js/Express + NeDB, деплой на Vercel.

## Главные задачи

1. **Переименование** — везде заменить «Endless Line» на **OdysseyTour** (именно так, на английском, слитно).
   В HTML: `<title>`, og:title, логотип, футер. В `translations.js` — название бренда одинаково во всех трёх языках (ru/en/de).
2. **Стиль** — цветовая схема **белый + оранжевый**. Современно, профессионально, читаемо. Свобода в дизайне.
3. **Баги** — пройтись по всем страницам, найти и починить всё, что не работает.

## Что нельзя ломать

### 🔴 Не трогать без крайней необходимости
- **`map-data.js`** — GeoJSON и данные туров. Только добавлять записи, не менять структуру экспорта.
- **`api/db.js`** — схема БД. Переименование полей сломает данные.
- **`nav.js`** — подключён на каждой странице; синтаксическая ошибка убьёт весь сайт.
- **`auth.js`** — JWT-авторизация, используется везде. После изменений тестировать вход/выход.

### 🟡 Редактировать осторожно
- **`variables.css`** — переименовал переменную → меняй везде, где используется.
- **`shared.css`** — переименовал класс → меняй во всех HTML.
- **`translations.js`** — три языка (ru/en/de) держать синхронными.

### 🟢 Свободно
- Любые `*-page.css` и `*-page.js`.
- HTML-контент внутри страниц.

## Перед любым изменением JS
1. Прочитать файл целиком — функции часто связаны.
2. Проверить, используется ли функция в других файлах.
3. Делать минимальное изменение — не трогать то, что не сломано.

## Заметки по бренду
- Логотип двухцветный: `Odyssey` (тёмный) + `Tour` (оранжевый), без пробела → читается как одно слово.
- Слитная форма бренда: **OdysseyTour**. В разбитой вёрстке: `Odyssey` / `Tour`.
- Имя репозитория `endless-line` и имена файлов с `Endless_Line` НЕ трогаем (это пути/артефакты, не бренд).
